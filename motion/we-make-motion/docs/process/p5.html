Limits, honestly

  • Listening I can’t hear the mix. It was verified by measurement and spectrogram, so the balance deserves a pair of human ears.
  • Live playback The browser version renders in real time, so very old phones may drop frames. The MP4 is the reference.
  • Variable fonts Canvas can’t animate font axes smoothly, so weight and width changes were done with transforms instead.
  • 3D The 3D master uses 3 motion-blur samples, not 24, because this machine renders WebGL in software. The live 3D player needs a reasonable GPU.
